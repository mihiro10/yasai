# 野菜価格統合ツール（統一品名マッピング付き）

取引先のCSVファイルを統合して、統一品名（カタカナ）を自動マッピングするWebアプリです。

## 🚀 デプロイ済みアプリ

Streamlit Cloudでデプロイ済みです。以下のURLからアクセスできます：

**https://yasai.streamlit.app** (Streamlit CloudのURLを確認してください)

## 📁 ファイル構成

### メインファイル（必須）
- `app.py` - Streamlit Webアプリ（メイン）
- `requirements.txt` - 必要なPythonライブラリ
- `README.md` - このファイル

## 🎯 機能

1. **4種類の取引先に対応**
   - マルエイ
   - 浜松ベジタブル
   - アグリ
   - おやさい（準備中）

2. **統一品名（カタカナ）の自動マッピング**
   - 品名から統一品名（カタカナ）を自動でマッピング
   - マッピングされていない品名がある場合、警告を表示

3. **出力形式**
   - 品名
   - 統一品名（カタカナ）
   - 取引先
   - 産地
   - kg単価
   - その週

## 📖 使い方

### ステップ1: ファイル名を準備

CSVファイルの名前を以下の形式に変更してください：

**形式:** `取引先名_YYYY_MM_DD.csv`

**例:**
- `マルエイ_2025_12_22.csv`
- `浜松ベジタブル_2026_01_12.csv`
- `アグリ_2026_01_19.csv`

**重要:**
- アンダースコア（_）で区切る必要があります
- 日付は `YYYY_MM_DD` 形式（アンダースコア区切り）
- 日付は**月曜日**である必要があります
- 例: 2025年12月22日は月曜日なので `2025_12_22` が正しい

### ステップ2: アプリにアクセス

Streamlit Cloudでデプロイされたアプリにアクセスします。

### ステップ3: ファイルをアップロード

1. 「CSVファイルをアップロード（1ファイルのみ）」セクションでファイルを選択
2. ドラッグ&ドロップまたは「Browse files」ボタンでファイルを選択
3. ファイル名が正しい形式か確認（取引先名と日付が表示されます）

### ステップ4: データを整理

1. 「🔄 データを整理」ボタンをクリック
2. データが処理されます（数秒かかります）

### ステップ5: 結果を確認

1. **警告の確認**
   - マッピングされていない品名がある場合、黄色の警告が表示されます
   - 未マッピングの品名が一覧表示されます

2. **データの確認**
   - データ数、取引先、週が表示されます
   - データプレビューで全データを確認できます

3. **データのコピー**
   - 「📋 コピー&ペースト用データ」セクションのデータをコピー
   - Google SheetsやExcelに貼り付け可能（タブ区切り形式）

### ステップ6: 出力データの形式

出力されるデータには以下の列が含まれます：

1. **品名** - 元の品名
2. **統一品名（カタカナ）** - マッピングされた統一品名
3. **取引先** - マルエイ、浜松ベジタブル、アグリ、おやさい
4. **産地** - 産地情報
5. **kg単価** - キログラム単価
6. **その週** - 週の日付（月曜日）

データは以下の順でソートされます：
1. その週（日付順）
2. 統一品名（カタカナ）（アルファベット順）
3. 品名（アルファベット順）
4. 取引先（アルファベット順）

## ⚠️ エラーと警告

### よくあるエラー

1. **「サポートされていない取引先です」**
   - ファイル名に取引先名が正しく含まれているか確認
   - 対応取引先: マルエイ、浜松ベジタブル、アグリ、おやさい

2. **「ファイル名の日付は月曜日である必要があります」**
   - ファイル名の日付が月曜日か確認
   - 例: 2025年12月22日は月曜日なので正しい

3. **「データが抽出されませんでした」**
   - CSVファイルの形式を確認
   - ファイルが正しい取引先の形式か確認

### 警告について

**未マッピング品名の警告**が表示された場合：
- その品名は統一品名（カタカナ）にマッピングされていません
- データは「未マッピング」として表示されます
- 必要に応じて、マッピング辞書に追加してください

## ⚠️ 警告機能

マッピングされていない品名がある場合、アプリは警告を表示します：

```
⚠️ 警告: X件の品名がマッピングされていません:
  - 品名1
  - 品名2
  ...
```

## 🔧 ローカルで実行

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで `http://localhost:8501` が開きます。

## 📊 統一品名（カタカナ）

64種類の統一品名（カタカナ）に対応しています。主なカテゴリ：

- **根菜類**: ゴボウ、サツマイモ、ニンジン、ダイコン、タマネギ、ジャガイモなど
- **葉菜類**: キャベツ、コマツナ、レタス、ハクサイ、ネギ、ホウレンソウなど
- **果菜類**: パプリカ、ピーマン、トマト、ミニトマト、ナス、カボチャなど
- **キノコ類**: ナメコ、エノキ、エリンギ、マイタケ、シイタケなど
- **果物類**: リンゴ、オレンジ、キウイ、レモン、イチゴ、バナナなど
