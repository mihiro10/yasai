# 野菜価格統合ツール（統一品名マッピング付き）

取引先のCSVファイルを統合して、統一品名（カタカナ）を自動マッピングするWebアプリです。

## 🚀 デプロイ済みアプリ

Streamlit Cloudでデプロイ済みです。以下のURLからアクセスできます：

**https://yasai.streamlit.app**

アプリ内にも「📖 使い方ガイド」セクションがあり、詳細な使い方を確認できます。

## 📁 ファイル構成

### メインファイル（必須）
- `app.py` - Streamlit Webアプリ（メイン）
- `requirements.txt` - 必要なPythonライブラリ
- `README.md` - このファイル

## 🎯 機能

### 1. 4種類の取引先に対応
- **マルエイ** - 完全対応
- **浜松ベジタブル** - 完全対応
- **アグリ** - 完全対応
- **おやさい** - 完全対応

各取引先のCSV形式に合わせた専用の抽出ロジックを実装しています。

### 2. 統一品名（カタカナ）の自動マッピング
- 136種類以上の品名バリエーションに対応
- 品名から統一品名（カタカナ）を自動でマッピング
- 直接マッピング、部分一致、逆方向部分一致の3段階で検索
- マッピングされていない品名がある場合、警告を表示

### 3. 価格エラー検出機能
- CSVファイル内の価格データに問題がある行を自動検出
- 無効な文字（`×`、`#VALUE!`など）や数値以外の文字を含む行を検出
- エラーが検出された行はデータから除外され、詳細が表示されます

### 4. 出力形式
出力されるデータには以下の列が含まれます：
- **品名** - 元の品名
- **統一品名（カタカナ）** - マッピングされた統一品名
- **取引先** - マルエイ、浜松ベジタブル、アグリ、おやさい
- **産地** - 産地情報
- **kg単価** - キログラム単価
- **その週** - 週の日付（月曜日）

データは以下の順でソートされます：
1. その週（日付順）
2. 統一品名（カタカナ）（アルファベット順）
3. 品名（アルファベット順）
4. 取引先（アルファベット順）

## 📖 使い方

### ステップ1: ファイル名を準備

CSVファイルの名前を以下の形式に変更してください：

**形式:** `取引先名_YYYY_MM_DD.csv`

**例:**
- `マルエイ_2025_12_22.csv`
- `浜松ベジタブル_2026_01_12.csv`
- `アグリ_2026_01_19.csv`
- `おやさい_2026_01_19.csv`

**重要:**
- アンダースコア（_）で区切る必要があります
- 日付は `YYYY_MM_DD` 形式（アンダースコア区切り）
- 日付は**月曜日**である必要があります
- 例: 2025年12月22日は月曜日なので `2025_12_22` が正しい

### ステップ2: アプリにアクセス

Streamlit Cloudでデプロイされたアプリにアクセスします。

### ステップ3: ファイルをアップロード

1. 「CSVファイルをアップロード（1ファイルのみ）」セクションでファイルを選択
2. ドラッグ&ドロップまたは「Browse files」ボタンでファイルを選択
3. ファイル名が正しい形式か確認（取引先名と日付が表示されます）

### ステップ4: データを整理

1. 「🔄 データを整理」ボタンをクリック
2. データが処理されます（数秒かかります）

### ステップ5: 結果を確認

1. **価格エラーの確認**
   - 価格に問題がある行がある場合、赤色のエラーメッセージが表示されます
   - エラーが検出された行の詳細が一覧表示されます
   - これらの行は自動的にデータから除外されます

2. **未マッピング品名の警告確認**
   - マッピングされていない品名がある場合、黄色の警告が表示されます
   - 未マッピングの品名が一覧表示されます
   - データは「未マッピング」として表示されます

3. **データの確認**
   - データ数、取引先、週が表示されます
   - データプレビューで全データを確認できます
   - データは自動的にソートされます（週 → 統一品名 → 品名 → 取引先）

4. **データのコピー**
   - 「📋 コピー&ペースト用データ」セクションのデータをコピー
   - Google SheetsやExcelに貼り付け可能（タブ区切り形式）


## ⚠️ エラーと警告

### よくあるエラー

#### 1. 「サポートされていない取引先です」
- **原因**: ファイル名に取引先名が正しく含まれていない、または対応していない取引先
- **解決方法**: 
  - ファイル名に取引先名が含まれているか確認
  - 対応取引先: マルエイ、浜松ベジタブル、アグリ、おやさい
  - 文字エンコーディングの問題（例: `ベジタブル` vs `ベジタブル`）は自動で処理されます

#### 2. 「ファイル名の日付は月曜日である必要があります」
- **原因**: ファイル名の日付が月曜日ではない
- **解決方法**: 
  - ファイル名の日付が月曜日か確認
  - 例: 2025年12月22日は月曜日なので `2025_12_22` が正しい
  - カレンダーで確認するか、日付を月曜日に変更してください

#### 3. 「データが抽出されませんでした」
- **原因**: CSVファイルの形式が取引先の形式と一致しない
- **解決方法**: 
  - CSVファイルの形式を確認
  - ファイルが正しい取引先の形式か確認
  - ファイルが破損していないか確認

#### 4. 「価格エラー: X件の行で価格に問題があります」
- **原因**: CSVファイル内の価格データに無効な文字や形式が含まれている
- **解決方法**: 
  - エラー一覧で問題のある行を確認
  - 価格列に `×`、`#VALUE!`、数値以外の文字が含まれていないか確認
  - 該当する行を修正してから再度アップロードしてください
- **注意**: エラーが検出された行は自動的にデータから除外されます

### 警告について

#### 未マッピング品名の警告
マッピングされていない品名がある場合、アプリは警告を表示します：

```
⚠️ 警告: X件の品名がマッピングされていません:
  - 品名1
  - 品名2
  ...
```

- **意味**: その品名は統一品名（カタカナ）にマッピングされていません
- **データへの影響**: データは「未マッピング」として表示されます
- **対応方法**: 
  - 必要に応じて、マッピング辞書に追加してください
  - または、手動で統一品名を設定してください

## 📊 統一品名（カタカナ）

136種類以上の品名バリエーションに対応しています。主なカテゴリ：

### 根菜類
ゴボウ、サツマイモ、ニンジン、ダイコン、タマネギ、ジャガイモ、ナガイモ、ヤマトイモ、サトイモ、レンコン、ショウガ、ミョウガなど

### 葉菜類
キャベツ、コマツナ、レタス、ハクサイ、ネギ、ホウレンソウ、ミズナ、チンゲンサイ、ミツバ、シソ、パセリ、パクチー、トウミョウ、モヤシ、ニラなど

### 果菜類
パプリカ、ピーマン、シシトウ、トマト、ミニトマト、ナス、カボチャ、キュウリ、オクラ、ズッキーニ、ゴーヤ、トウモロコシ、エンドウ、インゲン、セロリ、アスパラガスなど

### キノコ類
ナメコ、エノキ、エリンギ、マイタケ、シメジ、ブナシメジ、シイタケなど

### 果物類
リンゴ、オレンジ、キウイ、レモン、イチゴ、バナナ、グレープフルーツ、メロン、ナシなど

### その他
ブロッコリー、カリフラワー、チキン、タマゴなど

### マッピングの仕組み
1. **直接マッピング**: 品名が完全一致する場合
2. **部分一致**: 品名にキーが含まれている場合（長いキーから順に検索）
3. **逆方向部分一致**: キーに品名が含まれている場合

マッピングされない品名は「未マッピング」として表示され、警告が表示されます。
